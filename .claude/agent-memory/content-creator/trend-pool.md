# Shared Trend Pool

One section per brand, written by `/trend-scan {brand}`, read by the content-strategist, the content-creator, and the newsletter strategist. Each brand section carries a `Last scanned:` stamp. Consumers use the pool when the stamp is 3 days old or fresher; older than that, they run a live top-up (and recommend `/trend-scan {brand}` when older than 7 days).

The expensive gather runs once per brand here instead of once per agent. Never delete another brand's section when updating one.
